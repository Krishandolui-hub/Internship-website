
# Responsive Internship Board

## About the Project

Responsive Internship Board is a web-based platform that helps students explore internship opportunities.

Users can search internships, filter listings, save opportunities, and access application links.

## Features

- Responsive design
- Search internships
- Filter by location
- Filter by internship type
- Dynamic internship cards
- Save and remove internships
- Local Storage functionality
- Apply Now links

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Git and GitHub
